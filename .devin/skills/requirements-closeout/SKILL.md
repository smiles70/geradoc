# Requirements Closeout Skill

## Purpose
Certify a requirements-heavy work item only when traceability and evidence are complete.

## Closeout checks
- Every material requirement has an authoritative source.
- Every implementable requirement maps to an epic or deferment.
- Every claimed capability maps to code/research.
- Every completed capability maps to a test/evidence record.
- Critical gaps have owners and next actions.
- Conflicts are resolved, accepted, or escalated.
- Graph matches repository evidence.
- Current state and PR evidence are synchronized.

Return `PROCEED`, `PROCEED_WITH_CLEANUP`, `MANAGED_RISK`, or `BLOCK`.
