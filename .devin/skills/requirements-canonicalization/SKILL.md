# Requirements Canonicalization Skill

## Purpose
Normalize source requirements before identity, matching, or graph merge.

## Normalize
- Whitespace and punctuation
- Headings and requirement IDs
- Status vocabulary
- Authority labels
- Persona and journey names
- Acceptance-criterion ordering
- Source paths and section references

## Output
Emit canonical key, source hash, ontology version, parser version, and provenance. Canonicalization must be deterministic and reviewable.
