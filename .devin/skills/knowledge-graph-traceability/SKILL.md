# Knowledge Graph Traceability Skill

## Purpose
Build and refresh the canonical requirements graph.

## Required paths
`SourceArtifact → Requirement → Epic/UserStory → Capability → Test → Evidence`.

## Procedure
1. Read the ontology schema.
2. Link requirements to authoritative sources.
3. Link capabilities to code or explicit research artifacts.
4. Link tests and evidence to capabilities.
5. Identify missing edges.
6. Write graph and traceability report.

A graph edge must include source provenance and status.
