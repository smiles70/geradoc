Before: failures found

Failure 1 — Accessibility controls were visually present but not clickable.

Playwright reported that the fixed navigation overlay intercepted the Large text button.

Observed Playwright error
locator.click: Test timeout exceeded
<div class="absolute inset-x-4 top-4 z-50 ..."> intercepts pointer events
waiting for getByRole('button', { name: 'Large' })
Failure 2 — Sample processing/back path returned to ProcessingScreen.

The browser test found that transient processing history could return the user to the processing screen instead of the dashboard. Under parallel browser execution, the timer-only transition also made the sample journey flaky.

Observed visual state
button "Back to documents"
main:
  heading "We are working on your document"
  status: "Almost done..."
Failure 3 — Stale source result rendered JSON inside the PDF iframe.

A locally restored result had outlived its result metadata while the source file remained. The source endpoint returned an error object, which the browser displayed inside the “Your uploaded document” panel.

{"error":"Source document not found."}
