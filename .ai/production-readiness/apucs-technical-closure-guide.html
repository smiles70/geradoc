Operating rule

Graph lifecycle 
source artifact → requirement → epic/story → capability → test → evidence → owner/decision
Human/legal gates: This guide closes technical traceability. Human evaluation, patent, inventorship, and legal gates remain separate.

Session 3 — Candidate backends and hard constraints

Registry and hard gate 
class BackendRegistry {
  constructor() { this.backends = new Map(); }
  register(id, backend) { this.backends.set(id, backend); }
  get(id) { return this.backends.get(id); }
}

function hardGate(c) {
  return c.anchorRecall === 1 && c.actionRecall === 1
    && c.provenanceCoverage === 1 && c.contradictions === 0
    && c.adviceViolations === 0;
}

Link each constraint to its test with verified_by and attach output to evidence.

Session 4 — English and Spanish

Language normalization 
function normalizeAmount(value, language) {
  const raw = String(value).replace(/[^0-9,.-]/g, '');
  return language === 'es'
    ? Number(raw.replace(/\./g, '').replace(',', '.'))
    : Number(raw.replace(/,/g, ''));
}

Add separate English and Spanish fixtures for dates, amounts, negation, conditions, entities, actions, and advice. Unsupported languages must produce an explicit gap/state node.

Session 8 — Graph closeout

Closeout checklist 
[ ] No critical requirement lacks an owner
[ ] No completion claim lacks test/evidence

[ ] No orphan capability exists
[ ] Current state matches graph
[ ] PR evidence includes graph findings
[ ] JSON and graph validation pass
Verdict: PROCEED only when graph coverage, conflict status, tests, evidence, and current-state synchronization all pass.
